# Aula 5 — Lista ordenada, figura acessível e rodapé (fcc Steps 28–37)

## Passo 24 (fcc Steps 28–29)

**Teoria:** O código para uma lista ordenada (`ol`) é semelhante ao de uma
lista não ordenada, mas os itens de lista em uma lista ordenada são numerados
quando exibidos.

**Tarefa:** após o elemento `figure`, adicione outro elemento `h3` com o
texto:

`Coisas que gatos odeiam:`

Abaixo do `h3`, adicione uma lista ordenada (`ol`) com estes três itens:

1. tratamento contra pulgas
2. trovão
3. outros gatos

---

## Passo 25 (fcc Steps 30–33)

**Tarefa:** após a lista ordenada, adicione outro elemento `figure`. Dentro
do `figure` que você acabou de adicionar, envolva um elemento `img` com o
atributo `src` definido como:

`https://cdn.freecodecamp.org/curriculum/cat-photo-app/cats.jpg`

Para melhorar a acessibilidade da imagem que você adicionou, adicione um
atributo `alt` com o texto:

`Dois gatinhos dormindo juntos no sofá`

Após o último elemento `img`, adicione um elemento `figcaption` com o texto:

`Gatos odeiam outros gatos.`

---

## Passo 26 (fcc Step 34)

**Teoria:** O elemento `strong` é usado para indicar que algum texto é de
forte importância ou urgente.

**Tarefa:** no `figcaption` que você acabou de adicionar, indique que `odeiam`
é de forte importância envolvendo-o em um elemento `strong`.

---

## Passo 27 (fcc Steps 35–36)

**Teoria:** O elemento `footer` é usado para definir um rodapé para um
documento ou seção. Um rodapé geralmente contém informações sobre o autor do
documento, dados de direitos autorais, links para termos de uso, informações
de contato e mais.

**Tarefa:** após o elemento `main`, adicione um elemento `footer`.

Envolva um elemento `p` com o texto `Sem Copyright - freeCodeCamp.org`
dentro do elemento `footer`.

---

## Passo 28 (fcc Step 37)

**Tarefa:** transforme o texto existente `freeCodeCamp.org` em um link,
envolvendo-o em um elemento âncora (`a`). O atributo `href` deve estar
definido como `https://www.freecodecamp.org`.
