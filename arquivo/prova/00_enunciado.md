# Prova Prática de Programação Front-End — 2º Ano (Noturno)

## Projeto: CatPhotoApp



**Ambiente:** VS Code + Live Server · Entrega via **GitHub** (link no **Classroom**)

### Como funciona
Cada aula tem uma folha própria (`aula_1.md` até `aula_6.md`) 
 Você digita o código no
`index.html` seguindo os passos e, ao fim de cada aula, envia para o github e posta no classroom

**checkpoint**.

| Dia | Aula | Arquivo | Conteúdo |
|-----|------|---------|----------|
| 1 | Aula 1 | `aula_1.md` | h1, h2, p, comentários, main, indentação |
| 1 | Aula 2 | `aula_2.md` | img, src, alt, links, target, imagem-link |
| 1 | Aula 3 | `aula_3.md` | section, hierarquia de headings |
| 2 | Aula 4 | `aula_4.md` | ul/li, figure, figcaption, em |
| 2 | Aula 5 | `aula_5.md` | ol/li, strong, footer |
| 2 | Aula 6 | `aula_6.md` | head, title, lang, meta charset + prova final |

### Regras da prova
1. **Nada de copia-e-cola.** Todo código é digitado a partir das folhas.
2. Erros de digitação não tiram ponto — o que vale é o código funcionar.
3. Ao fim de cada aula, envie para o github.
4. Sem IA e sem internet livre. Você pode consultar apenas as folhas e seus
   materiais da disciplina.
5. Arquivos da prova: `index.html` (único HTML), `respostas.md` (Aula 3),
   `estrutura.md` (Aula 6).

### Como entregar (obrigatório — leia `entrega_github_classroom.md`)
1. Crie o repositório `cat-photo-app` no GitHub (dia 1, primeira aula).
2. Faça **um commit ao fim de cada aula** — os commits são a prova da sua
   evolução e contam a favor na rubrica.
3. Ao final, envie o **link do repositório** na tarefa do Classroom:
   `https://github.com/SEU-USUARIO/cat-photo-app`
