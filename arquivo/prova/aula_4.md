# Aula 4 — Listas e legendas (fcc Steps 22–27)

## Passo 19 (fcc Steps 22–23)

**Teoria:** Para criar uma lista não ordenada de itens, você pode usar o
elemento `ul`. Dentro dele, cada item de lista usa o elemento `li`.

**Exemplo:**

```html
<ul>
  <li>petisco</li>
  <li>bolinha</li>
</ul>
```

**Tarefa:** dentro da segunda `section`, crie um `h3` com o texto
`Coisas que gatos amam:` e, após ele, uma lista não ordenada (`ul`) com
três itens:

- erva de gato
- ponteiros laser
- lasanha

## Passo 21 (fcc Step 25)

**Teoria:** O elemento `figure` representa conteúdo autocontido e permite
associar uma imagem à sua legenda.

**Tarefa:** envolva a imagem que você acabou de adicionar dentro de um
elemento `figure`.

---

## Passo 22 (fcc Step 26)

**Teoria:** Um elemento de legenda de figura (`figcaption`) é usado para
adicionar uma legenda que descreve a imagem contida dentro do elemento
`figure`.

**Exemplo:**

```html
<figure>
  <img src="image.jpg" alt="A description of the image">
  <figcaption>A cute cat</figcaption>
</figure>
```

**Tarefa:** após a imagem aninhada no elemento `figure`, adicione um elemento
`figcaption` com o texto:

`Gatos amam lasanha.`
